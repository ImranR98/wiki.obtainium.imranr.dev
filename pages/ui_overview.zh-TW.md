# 介面概述 {#ui-overview}

螢幕底部的分頁列是查看 Obtainium 的主要方式。

## 應用程式清單 {#apps-page}

主畫面包含 Obtainium 正在追蹤的應用程式清單，並提供每個應用程式的基本資訊。

在此頁面中，您可以使用螢幕底部的按鈕同時對多個應用程式執行各種操作。選擇一個或多個應用程式後，可以長按進入多選模式，也可以使用“全選”按鈕。可用的批次操作包括更新、安裝、刪除、分類、置頂/取消置頂、分享應用程式連結或匯出連結，以及將所選應用程式標記為已更新。

應用程式可以分配到類別，類別會顯示為每個應用程式條目左側的色條。當在設定中啟用"按類別分組"時，應用程式清單將按類別分為可展開的區塊。

在單一應用程式的詳細檢視畫面中，您可以查看應用程式的版本資訊、發布日期、更新記錄和 APK 簽署憑證雜湊值（長按複製）。如果偵測到儲存庫已重新命名，將會出現顯著提示，並附帶自動更新應用程式連結的選項。

您還可以按下"篩選"按鈕來篩選特定的應用程式。這樣就可以只查看符合特定條件（如已安裝/未安裝、最新/非最新版、來源網站、類別等）的應用程式。

## 新增應用程式到應用程式清單 {#add-app-page}

此頁面可讓您透過應用程式來來源連結新增應用程式。

當您輸入應用程式來來源連結時，Obtainium 會自動偵測應使用哪種[應用程式來源](app_tracking.md/#basics)，並顯示相關選項。如果連結與任何受支援的應用程式來源不對應，則會預設選擇“[HTML](sources.md/#html)”源。該應用程式來源是一種通用的後備方案，在某些情況下可能有效。如果你認為 Obtainium 做了錯誤的選擇，你可以手動指定要使用的來源類型。

對於大多數應用程式來源，輸入的連結不需要太精確；例如，GitHub 來源會接受任何包含基礎儲存庫連結的 GitHub 連結（例如，`https://github.com/ImranR98/Obtainium/releases/latest` 會自動縮減為 `https://github.com/ImranR98/Obtainium` ）。不過，在兩種情況下，您的連結必須更加精確：

1. 使用 HTML 來源時
      - 例如，Tor Android APK 位於 `https://www.torproject.org/download/` ，因此只輸入 `https://www.torproject.org/` 是不行的。
2. 手動選擇應用程式來源時（覆蓋 Obtainium 的 HTML 備援選擇）

此頁面還可讓您在支援此功能的來源中搜尋應用程式（[匯入/匯出](#importexport-page) 頁面也提供了單獨的搜尋工具）。請注意，一個應用程式出現在搜尋結果中並不意味著它將被成功新增，它還需要滿足所有其他條件。

最後，該頁面列出了所有支援的應用程式來源，以及來源是否可搜尋等附加資訊。

## 匯入/匯出 {#importexport-page}

透過此頁面，您可以匯出 Obtainium 資料，以便日後匯入。您還可以啟用自動匯出功能，只要資料有所變更，就會自動匯出，並控制是否在匯出中包含機密資訊（如 API 權杖）。

此頁面還提供了匯入大量應用程式的各種其他方法：

- **搜尋**：跨支援的來來源搜尋並批次匯入結果。
- **連結清單匯入**：貼上或載入包含應用程式連結清單的檔案，一次性匯入所有應用程式。
- **批次源匯入**：從批次源（如 GitHub 使用者星標的儲存庫）匯入應用程式。

本頁的搜尋工具還可讓您搜尋需要指定應用程式來源伺服器/網域的來源，例如[第三方 F-Droid 儲存庫](sources.md/#f-droid-third-party-repo)。

## 設定 {#settings-page}

該頁面提供各種使用者介面和行為設定，按以下部分組織：

- **更新**：背景更新間隔、前景服務模式、Wi-Fi/充電限制、啟動時檢查、並行下載、用於靜默安裝的 Shizuku 整合（可選擇偽裝成 Google Play），以及在安裝前驗證 APK 的 AppVerifier 整合。
- **來源專屬**：特定來源的憑證（如 GitHub/GitLab 個人存取權杖）和其他來源專屬設定設定。
- **外觀**：主題（系統/淺色/深色）、黑色模式、Material You 動態顏色、自訂強調色、排序方式、語言覆蓋、系統字型、應用程式內 WebView、類別分組和頁面過渡設定。
- **類別**：建立、重新命名和刪除類別以組織您的應用程式。

設定頁面底部還提供指向原始碼、本 Wiki、眾包應用程式設定和應用程式記錄的連結。
